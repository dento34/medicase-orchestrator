# Patient Mini Web App

QR-launched mini web app that opens on the patient's phone in their own language.

## Purpose

When the volunteer scans a QR code generated by Maestro Case at intake, this app opens on the patient's phone with:

- Auto-detected language (browser locale + first utterance)
- Voice prompts in the patient's language (TTS)
- Voice recording capture for STT
- Fallback **tap-card visual triage** (body map, pain scale icons) for low-resource languages or non-verbal patients
- Privacy-first: session ends when case closes, no data persists on device

## Stack

- **Next.js** (App Router)
- **Vercel** (deployment, free tier sufficient)
- **Web Speech API** (browser TTS / STT, no extra dependency)
- **Anthropic API** (translation, prompts) — server-side only, key never in client
- **No tracking, no analytics, no cookies**

## Launch URL pattern

```
https://medicase-patient.vercel.app/?case=<case_id>&lang=<initial_lang>
```

The `case_id` is signed by the Maestro Case during QR generation; the app verifies signature on load.
